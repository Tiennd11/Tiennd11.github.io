# Personal site — Tien Nguyen

Static personal and academic site. No build step, no dependencies, no trackers.
Deployed with GitHub Pages.

**Live:** https://tiennd11.github.io/

```
index.html     structure and all prose content
styles.css     design tokens, layout, figure styling
pubs.js        publication data + journal/conference split + filtering
diagrams.js    plays the research figures only while they are on screen
field.js       hero canvas (plate-mode isolines, marching squares)
assets/        portrait, favicon, Zalo QR
tools/figs.py  regenerates the eight research figures
```

Page order: hero → research interests → applied work → toolkit → publications →
education → contact.

## Design notes

- **Palette** is the [Okabe–Ito colourblind-safe set](https://jfly.uni-koeln.de/color/),
  the same family as the `#0072B2` used in the LaTeX CV.
- **Hero canvas** draws isolines of superposed bending modes on a rectangular plate,
  `w(x,y,t) = Σ aₖ sin(mₖπx) sin(nₖπy) cos(ωₖt + φₖ)`, with scattered collocation
  points. Contours come from marching squares; mode numbers are chosen from the
  canvas size so a contour cell stays about the same size on any screen. Capped at
  30fps, paused offscreen and when the tab is hidden, static under
  `prefers-reduced-motion`.
- **Research figures** are eight inline SVGs, generated by `tools/figs.py` so the
  geometry is computed rather than eyeballed — the arm poses are real inverse
  kinematics, the hex lattice really tiles, the attention map really is causal.
  They animate only while their card is on screen.
- Dark mode follows the system setting. Keyboard navigable, no horizontal scroll
  at 375px, prints cleanly.

## Editing

### Add a publication

Open `pubs.js` and add an entry to `PUBS`:

```js
{ y: 2026, type: "journal", tags: ["sciml", "robotics"],
  t: "Title of the paper",
  a: "*D. T. Nguyen*, A. Coauthor, B. Coauthor",
  v: "Journal Name",
  doi: "10.1016/j.example.2026.123456" }     // optional
```

- `type` — `"journal"` or `"conference"`; the two lists render separately with
  their own counts.
- `a` — wrap your own name in `*asterisks*` to bold it; add `^` after a name to
  mark equal contribution.
- `tags` — any of `sciml`, `robotics`, `fracture`, `structdyn`, `uq`, `agentic`.
  These drive the filter chips.

Entries sort by year automatically. Only published and accepted work is listed —
nothing under review, under revision, or submitted.

### Add an applied-work project

In `index.html`, find the `ADD ANOTHER PROJECT HERE` comment in the `#work`
section and copy the template block above it.

### Change a research figure

Edit `tools/figs.py`, then regenerate and splice:

```bash
python tools/figs.py
```

It writes `interests.html`; paste that into the `#research` section of
`index.html`, replacing everything between `<div class="shell">` and the closing
tags. Figure styling lives in the "research interests" block of `styles.css`.

### Regenerate the Zalo QR

```bash
pip install segno
python -c "import segno; segno.make('https://zalo.me/0356293282', error='m').save('assets/zalo-qr.svg', scale=1, border=2, dark='#0E1B26', light=None, omitsize=True)"
```

The QR relies on the white `.qr-plate` and its padding for the quiet zone — keep
both if you move it.

## Running locally

```bash
python -m http.server 8000
```

Then open <http://localhost:8000>.

## Deploying

Pushing to `main` publishes automatically — GitHub Pages serves the repository
root. Settings → Pages → Source: *Deploy from a branch*, branch `main`, folder
`/ (root)`.
